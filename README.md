# Employee Management System

## 📌 Project Overview
This is a **3-Tier Architecture Employee Management System** built using C#.

The system is structured into:
- Presentation Layer (UI)
- Business Layer (Business Logic)
- Data Access Layer (Database Access)

The main focus of this project is backend architecture and clean separation of concerns.

---

## 🏗️ Architecture
- Presentation Layer: Handles user interaction using Views and Interfaces.
- Business Layer: Contains business logic, services, and mapping.
- Data Access Layer: Responsible for database operations and DTOs.

---

## ⚙️ Technologies Used

- ADO.NET
- 3-Tier Architecture
