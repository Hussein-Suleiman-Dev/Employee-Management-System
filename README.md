# Employee Management System

## Overview
A backend-focused desktop system for managing employees, departments, and projects using C# and SQL Server.  
The project is built with a 3-Tier Architecture focusing on business logic and database design.

## Features
- Employee management (CRUD operations)
- Department management
- Project management
- SQL Server database integration

## Technologies Used
- C#
- SQL Server
- ADO.NET
- 3-Tier Architecture

## Current Status
Core backend functionality and database operations are implemented.  
Additional features such as user roles and permissions will be added in future updates.
